# 自动刷快手极速版广告

## 序言


- 本代码基于国产自动化插件Auto.js实现，仅支持Android平台。
- 手机安装AutoJs并联网后，即可自动运行收益类的App获得收益，无需其他插件设备，无需ROOT。
- 由于各大收益类APP平均每周更新一次，本代码不一定能够及时匹配。
- 目前仅支持快手极速版
